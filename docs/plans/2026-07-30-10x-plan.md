## What "10x better" means here

Murmur's promise is: *press a key, speak, correct text appears at your cursor — instantly, accurately, offline.* Today it delivers that promise slowly (full-pass Cohere after you stop), fragilely (v0.4.2–v0.4.10 were eight consecutive fixes to the same silence-gate/hands-free subsystem), and with accuracy gaps (punctuation half-shipped, no personal vocabulary). 10x is not more features — it is making the core loop feel instant and never wrong.

Measurable targets (all on M1 8 GB):

| Metric | Today | Target |
|---|---|---|
| Time from stop-speaking to final text (10 s utterance) | ~2–4 s (full Cohere pass) | **< 700 ms** |
| Time to first visible word while speaking (streaming) | 3+ s (chunk cadence) | **< 1 s** |
| Dropped/silently-lost utterances | recurring (0.4.4, 0.4.10 class bugs) | **0** in regression suite |
| zh-en code-switch CER | FireRed-level only in V1 | FireRed-level **in streaming too** |
| Streaming mode | opt-in experimental | **default on** |
| CI | build only, no tests | **tests gate every PR** |

Execution order matters: foundation first (or every later phase re-fights the 0.4.x fires), then land the WIP, then the engine swap, then accuracy, then default-on.

## Hard execution constraint: no model-loading tests on the Mac mini

The development Mac mini has limited RAM; tests that load transcription models have **crashed the machine** (see `Murmur/Tests/TestHeavyGate.swift`). Non-negotiable rules for the executor:

- **Never** set `MURMUR_RUN_HEAVY_TESTS=1` on the local machine — not to verify a fix, not to run a benchmark, not "just once." Local runs are always plain `swift test` (light tier).
- Anything that loads Cohere, FireRed, or SenseVoice weights (heavy tests, the Phase 3 eval set, `make bench`) runs **only** on a GitHub-hosted CI runner, or locally only when Ronica explicitly says to run it in that session.
- All new tests written under this plan must pass in the light tier by default. If a test genuinely needs model weights, gate it behind `TestHeavyGate` — but prefer designing it not to need them (fakes/fixtures).

A repo with ~460 tests and no CI gate is why regressions ship.

### 0.2 Audio-fixture regression harness for the silence gate / hands-free
This subsystem burned eight releases because every fix was verified by hand. Build a deterministic test tier that feeds **recorded WAV fixtures** (existing `Murmur/test_fixtures/` plus new ones) through `AudioService`'s gate logic and `VadService` with a fake clock:

- Fixtures to create: 1-word fast utterance ("yes", "好"), noisy-café background, long pause mid-sentence, trailing silence at each slider extreme, pure silence.
- Assert: gate passes/blocks correctly, hands-free auto-stop fires at the right time and **never mid-utterance**, `hadAnySpeechSegment` bookkeeping survives the poller draining segments.
- Refactor only as needed for injectability (clock, VAD seam). `AudioService.swift` is 506 lines with one referencing test file — the highest-risk untested code in the repo.
- The harness must run in the **light tier**: inject a fake VAD (scripted segment timings) rather than loading real Silero, so the whole suite is safe on the Mac mini. A thin heavy-gated variant may additionally run the same fixtures through real Silero on CI only.

Acceptance: every 0.4.x CHANGELOG bug has a named regression test that fails on the pre-fix logic.

## Phase 2 — Hybrid engine: SenseVoice streams, heavy engine finalizes

This is the biggest single lever. The spike (`docs/spikes/2026-06-28-sensevoice-spike.md`) measured SenseVoice-Small int8 at **239 MB, RTF 0.017 (~58× realtime)** — re-transcribing a 12 s window costs ~200 ms, versus seconds for Cohere. Its one dealbreaker (zh-en code-switch mangling) doesn't matter for the streaming pass, because Phase 1's architecture already ends every session with a **full-pass replacement** — run that finalize pass on FireRed/Cohere and code-switch errors get repaired at stop time.

**Gate first (blocking):** the SenseVoice model ships under the ModelScope agreement. Verify redistribution/commercial terms before any wiring. If terms fail, fall back to Phase 2-alt below.

1. Commit the spike artifacts (`docs/spikes/`, `Scripts/sensevoice_spike.py`, `SenseVoiceTranscriptionService.swift`) so the work is on record.
2. Wire SenseVoice into `ModelManager` as an auxiliary streaming model (download, manifest verification, delete) — mirror the Silero VAD / CT-Transformer pattern, not a new user-facing backend.
3. Extend `TranscriptionRouter`: V3 streaming pass → SenseVoice; V3 finalize pass → whatever the active backend is (Cohere or FireRed). V1 unchanged.
4. Retune the streaming loop for the fast engine: with ~200 ms passes, the VAD `minSilenceDuration` hack (0.8 s, v0.4.8) can likely return toward 0.25 s, and window passes can run on a cadence rather than only on chunk boundaries. Measure, don't assume.
5. Emotion/event tags from SenseVoice: discard for now (the service already parses them; don't surface).
6. Benchmark against Phase 1 baseline: time-to-first-word, streamed-vs-final edit distance, CPU (the `CPULoadMonitor` fallback threshold may need retuning since load drops massively).

**Phase 2-alt (if license fails):** keep Cohere for streaming but exploit Phase 1's serialized-window design with a smaller window cap and cadence tuning; expected gains are smaller but real.

**Exit criteria:** streaming time-to-first-word < 1 s; finalize pass preserves FireRed-level zh-en accuracy; license question answered in writing in the repo.

## Phase 3 — Accuracy: the text that appears is the text you meant

1. **Execute the corrector-glossary plan** (`docs/superpowers/plans/2026-04-25-corrector-glossary.md` — fully specced, all tasks unchecked): user-editable glossary of authoritative spellings + correction system prompt. This is the cheapest large accuracy win for anyone dictating names, jargon, or product terms.
2. **Personal vocabulary that learns.** When the user edits injected text within the undo window, or the finalize pass replaces streamed text, those diffs are training signal. Store frequent corrections locally; feed them into the glossary automatically (with a review UI in Settings, not silently).
3. **Punctuation consolidation.** Decide the fate of the v0.3.1 classifier spec (handoff 095): the CT-Transformer ASR-punc path shipped and works for zh; evaluate whether it plus the LLM corrector already meets the ≥ 85% bilingual F1 gate on the 50-utterance eval set the spec defines. Build that eval set (25 EN LibriSpeech / 20 ZH AISHELL-1 / 5 code-dictation) as a scripted benchmark regardless — it becomes the accuracy regression suite. Only build the classifier if the eval shows a real gap.
4. **Auto-detect cleanup.** The Cohere-echo language retry (`AppCoordinator.transcribeWithAutoDetectIfNeeded`) is heuristic (CJK ratio > 30%). SenseVoice does per-utterance LID natively and is nearly free — use its LID output as the detect signal when available.

**Exit criteria:** eval-set benchmark scripted and runnable on CI runners (heavy tier — never on the Mac mini); glossary shipped; accuracy numbers before/after recorded.

## Phase 4 — Make streaming the product (default-on + UX debt)

Streaming stops being "experimental" only when its rough edges are gone. The UAT record (handoff 058, 099) already lists them.

1. **UAT P1s from 058:** visible indication when streaming falls back to V1 (CPU monitor) and when focus-guard abandons a session. Silent mode-switches are trust-killers.
2. **Clipboard borrowing:** V3 injects via clipboard on every chunk (058 P2). Investigate CGEvent typing or AX insertion for streaming deltas — deltas are now small (stable-prefix), which makes keystroke injection viable where whole-chunk paste wasn't.
3. **History search** (top UAT complaint from 041): a filter field over `TranscriptionHistoryService` in `RecentHistoryView`. Small, repeatedly requested.
4. **Default-on decision:** after Phases 1–2 have burned in (crash-free sessions, edit-distance ratio consistently < 1%), flip `streamingInputEnabled` default to true for new installs, keep the off switch. Run UT (uat-user-tester) pass first per team protocol.
5. **Pill polish:** language badge visible during transcribing (099's three-line fix), no developer-facing chunk counts anywhere.

**Exit criteria:** UT pass with zero P0s; streaming default-on for fresh installs; v1.0 tag.

## Explicitly not in this plan

- **New surfaces** (iOS, Windows, cloud sync) — the core loop isn't 10x yet; breadth would dilute.
- **Speaker diarization, meeting summaries** — V2-window nice-to-haves (041), not the dictation loop.
- **Replacing Cohere wholesale with SenseVoice** — spike verdict is clear: streaming yes, sole engine no (zh-en code-switch CER 23.1%).
- **Telemetry** — local metrics only.
